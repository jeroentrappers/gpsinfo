What it does

Everything the GPS chip can tell you, on one screen.

Raw GNSS, 7 constellations

Per-satellite signal strength and sky position across GPS, GLONASS, Galileo, BeiDou, QZSS, SBAS and IRNSS — straight from the Android GNSS APIs.

Trail recording

Standard GPX 1.1 with Garmin TrackPointExtension (speed, course). Foreground service keeps capture alive when the app is backgrounded or the screen is off.

Offline trail map

OpenStreetMap-backed map with on-demand tile pre-cache for a region, so the trail map works fully offline once you've prepared an area.

Speed + elevation chart

Dual-axis chart over the recorded trail with a scrubber that moves a cursor along the polyline. Tap any point for the full sample readout.

Tilt-corrected compass

Magnetic + true heading, declination, inclination. The trail map rotates with you in heading-up mode using the same compass pipeline.

Trail simplification

3D Ramer–Douglas–Peucker over the recorded points to clean GPS noise without losing route shape. Three accuracy presets; preview before you commit.

Sun arc overlay

Where the sun rose, peaked and set on the day you recorded a trail, anchored to the trail's start. Same solar calculator that drives the dashboard's day/night world map.

Share & import GPX

Hand a recorded GPX to any app via the share sheet, save it via the system file picker, or import a GPX file from anywhere. Every transfer is user-initiated.

No Play Services

Runs on de-Googled devices (GrapheneOS, LineageOS, /e/OS, …). Location comes straight from LocationManager + GnssStatus.

Privacy

The default is silence.

Most GPS apps phone home before they show you a coordinate. GPSinfo is the opposite — the only network call it ever makes is an anonymous OpenStreetMap tile fetch, and only when you actively open a trail map.

  • No analytics SDK
  • No crash reporter
  • No ads, no attribution SDK
  • No Firebase, no Google Analytics
  • No social SDKs, no Facebook pixel
  • No account, ever
  • Doesn't read your contacts, photos, or other apps' data
  • Doesn't send your location anywhere
