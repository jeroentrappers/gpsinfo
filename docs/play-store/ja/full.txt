GPSinfo は Android 向けのオフラインファースト GPS ダッシュボード兼ガイド付きラン用コンパニオンです。

GPS の情報を 1 画面に集約。GPX 記録、Bluetooth 心拍計、外部通信なしでペースを指導するスポーツビューも搭載。Google Maps SDK なし、Play Services なし、テレメトリなし、アカウントなし、課金なし。

ハイカー、セーラー、サイクリスト、ランナー、ライダー、アマチュア無線家、GNSS 好き、位置データを端末から出したくない人へ。

▌ ダッシュボード
• 位置を 5 形式で表示 — DMS、十進、Plus Code、Maidenhead、MGRS。タップで切替、長押しでコピー
• 高度、軸別精度、測位品質バッジ
• GPS、GLONASS、Galileo、BeiDou、QZSS、SBAS、IRNSS の衛星数と信号強度
• 実方位角・仰角でプロットし、コンステレーション別に色分けするスカイビュー
• 傾き補正コンパス(磁気/真方位、偏角、伏角)
• ハードアイアン補正を推定する専用の磁気センサー校正画面
• スケール自動調整の速度計、HUD ミラーモード
• 太陽位置、日の出/日の入り、昼の長さ、世界地図上の昼夜境界線

▌ トラック
• 標準 GPX 1.1 + Garmin TrackPointExtension(速度、針路、心拍)で記録
• フォアグラウンド動作で画面オフ時も継続
• OpenStreetMap にポリラインとマーカーで描画
• 速度・高度・心拍グラフ、任意点を見られるスクラバー
• ヘディングアップ表示、太陽弧オーバーレイ
• タイル事前キャッシュでオフライン利用可
• Ramer–Douglas–Peucker で GPS ノイズを除去
• GPX のインポート、共有、保存。ワンタップでウェイポイント取得

▌ ナビゲーション
• 往路を戻る:記録済みルートを相対方位の矢印で逆走
• 地図タップで目的地指定、方位ナビを実行
• ウェイポイントごとに距離、ETA、ペース目標差分を表示

▌ スポーツビュー(ガイド付きラン/ウォーク)
• フルスクリーン:経過時間、距離、現在/平均ペース、速度、ケイデンス、ストライド
• ペース偏差計 — 速すぎ/目標通り/遅すぎを一目で
• 心拍ゾーン計(設定可、ルート単位の上書き可)
• 前方区間の強度を勾配で色分け、次の登りまでの ETA
• ペース目標 — ルート全体または区間ごと
• 端末内 TTS による音声コーチング(任意)。音楽を遮らず音量を下げて流します
• ラン終了後の総合スコア(0–100)— ペース達成度と心拍ゾーン達成度をブレンド

▌ Bluetooth 心拍計
• 標準 BLE 心拍計とペアリング(Polar、Wahoo、Garmin チェストベルト等)
• GATT 直接接続 — ベンダー SDK、クラウド、API キー不要
• BPM をライブ表示、GPX のポイントごとに記録

▌ プライバシー
• アナリティクス、クラッシュレポート、広告、外部トラッカーなし
• 位置データ、心拍、TTS 音声は端末内に留まります
• 通信はトラックマップを開いたときの匿名 OpenStreetMap タイル取得のみ
• ポリシー:https://jeroentrappers.github.io/gpsinfo/privacy.html

▌ Play Services 不要・課金なし
脱 Google デバイス(GrapheneOS、LineageOS、/e/OS など)でも動作。位置情報は Android の GNSS API から直接取得。寄付は Liberapay と GitHub Sponsors で、機能制限はありません。

▌ 12 言語対応
